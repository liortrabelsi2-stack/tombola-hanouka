# Tombola de Hanouka

Chacun s'inscrit avant une date. À l'heure dite, le tirage se fait tout seul : la roue donne à chaque inscrit le prénom de la personne à qui offrir un cadeau, et personne ne sait qui le gâte.

- `index.html`, `style.css`, `app.js` : le site, sans dépendance.
- `supabase/migrations/` : la base de données (tables privées et fonctions appelées par le site).
- Espace organisateur : ajouter `#admin` à l'adresse du site.
